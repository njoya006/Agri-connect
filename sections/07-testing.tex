\section{Testing}

\subsection{Testing Strategy}
We use multiple testing levels:
\begin{itemize}[leftmargin=*]
	\item Unit testing for individual components
	\item Integration testing for API endpoints
	\item End-to-end testing for user flows
\end{itemize}

\subsection{Testing Tools}
\begin{itemize}[leftmargin=*]
	\item Django: pytest, Django Test Framework
	\item Frontend: Jest, React Testing Library
	\item API: Postman, Insomnia
	\item E2E: Cypress (optional)
\end{itemize}
